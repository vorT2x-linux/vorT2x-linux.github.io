Before you start#

You need:

  • An Intel Mac with the T2 chip, running macOS.
  • An empty USB drive. It will be erased. 8 GB or more is plenty.
  • An internet connection, on the Mac and later in Fedora.
  • Free disk space for Fedora. In macOS, use Disk Utility to make room (we suggest 50 GB or more).

Back up first. Installing an operating system next to macOS changes your disk. Make a Time Machine backup before you begin.

Allow your Mac to start Linux

T2 Macs only start operating systems Apple trusts, so you need to relax that once:

  1. Restart and hold ⌘ R until macOS Recovery opens.
  2. Choose Utilities › Startup Security Utility and sign in.
  3. Set Secure Boot to No Security.
  4. Set External Boot to Allow booting from external or removable media.

Set up Touch ID in macOS

Touch ID on Linux uses the fingerprints stored by macOS. If you want it, add your fingers in System Settings › Touch ID before you install Fedora.

Make the USB stick#

Connect the empty USB drive to your Mac, open Terminal and run:

$ curl -fsSL https://github.com/vorT2x-linux/vort2x/releases/latest/download/install-vort2x-fedora.sh | bash

This downloads the latest VorT2x installer kit, checks it, and starts it. Then:

  1. Choose Fedora Workstation, Fedora KDE or the COSMIC spin. Workstation (GNOME) gets the most attention.
  2. Choose the external USB drive.
  3. The script downloads Fedora and verifies it, then asks you to type ERASE diskN to confirm. Nothing is erased before that.

The stick gets the T2 keyboard and trackpad drivers, Wi-Fi for the live system, and Apple's Wi-Fi firmware for the installed system. On Macs whose Bluetooth runs over PCIe it also carries the Bluetooth firmware.

From a copy of the code

Developers can run the same tool from a clone of the repository, also with an ISO you already downloaded:

$ git clone https://github.com/vorT2x-linux/vort2x.git && cd vort2x
$ bash ./scripts/macos/prepare-fedora-installer.sh --help

Install Fedora#

  1. With the stick connected, restart and hold ⌥ Option. Pick the orange EFI Boot disk.
  2. Choose Start Fedora Live with VorT2x input drivers. The standard Fedora entry is there as a fallback, and a Troubleshooting section has options such as basic graphics or the dedicated GPU switched off.
  3. Start the Fedora installer and install as usual, into the free space you made.

Reinstalling? For a clean reinstall, format the existing Linux /boot partition in the installer.

If no Wi-Fi network shows up in the live system, open a terminal and run sudo /run/vort2x/vort2x-live-wifi.

First login#

Log in to your new Fedora and connect to Wi-Fi. The VorT2x installer opens in a terminal by itself and works in two phases:

  1. Phase 1 updates Fedora and prepares the newest kernel. Reboot when it asks.
  2. Phase 2 starts by itself after the reboot and installs VorT2x: drivers, services, apps and fixes. Read its summary, then reboot once more.

Don't close the window while it works. If no terminal appears, open one and run vort2x-install as your normal user, without sudo. It asks for your password when it needs it.

Optional parts are offered during the install: the Touch Bar daemon on Macs with a Touch Bar, and, on GNOME, the Eddy desktop theme and login-screen branding.

The install log is kept in ~/.local/state/vort2x/install.log.

Updating#

Fedora updates come from Fedora as usual. The T2 drivers are DKMS modules and rebuild themselves for each new kernel.

VorT2x updates come in releases. Open the VorT2x Update app to see what's new and install only the parts that changed, or run:

$ vort2x-install

How releases work

Each VorT2x release says which Fedora versions it supports. Your Mac always moves to the newest release made for the Fedora version it runs. When a new Fedora comes out, it gets its own release, and Macs still on the older Fedora stay on the last release made for it. The current release supports Fedora 45.

Touch ID#

VorT2x connects the T2's fingerprint sensor to Fedora's standard fingerprint service, fprintd, and switches on fingerprint login. You can then unlock your session and approve sudo with a finger.

Touch ID is installed on MacBooks only. Desktop Macs have no sensor, so the installer skips it, and removes it if an earlier version added it.

  • It uses the fingerprints you enrolled in macOS. To add or remove fingers, do it there.
  • Press Esc during a fingerprint prompt to stop it and type your password instead.

Touch Bar#

On MacBook Pros with a Touch Bar, the installer offers the VorT2x Touch Bar daemon. The bar stays dark until you touch it or press Fn, and it has three layers:

  • media keys
  • F-keys
  • keys the MacBook keyboard lacks: Print, Insert, Delete, Home, End, Page Up and Page Down

Swipe with two fingers on the lit bar to move between layers. Hold Fn for a moment to switch between media keys and the layer you used last. Key presses get haptic feedback, and a Touch ID prompt appears when a fingerprint is wanted.

You can add up to four personal keys to the third layer in ~/.config/vort2x-touchbar/keys.toml.

Audio#

VorT2x installs audio processing for the internal speakers and microphones, modelled on what macOS applies to each model: equalisation, crossovers, compression, limiting and virtual bass. It's chosen automatically for your Mac model.

Headphones and headset microphones are left untouched. Models without a profile keep Fedora's default sound.

Graphics#

MacBook Pros with both Intel and AMD graphics get a GPU control app that matches the Mac: T2 GPU Control or T2 Hybrid GPU Control. The installer picks the right one.

Fans and power#

T2 Fan Control runs the fans from a curve that follows your Mac's temperatures. Leave it on Automatic unless you want the SMC, the Mac's own power controller, to run the fans as it does at boot.

Fan boost on the T2 iMacs

A game can heat the GPU much faster than a temperature curve can follow. So on the iMac Pro and the 2020 27-inch iMacs, fan control also watches how busy the AMD GPU is:

  • When the GPU is 80% busy or more on two readings in a row, a quarter of a second apart, the fans go straight to full speed.
  • They stay at full speed until 30 seconds after the GPU was last busy. Then the normal curve takes over and they slow down gradually.
  • Short spikes on the desktop, such as opening an app or playing a video, don't trigger it.

The boost works only while fan control is on Automatic. MacBook Pros with an AMD GPU don't get it, because full fans in every game would just be noise on a laptop.

GPU clock limit on the iMac Pro

Without help, starting a game could make the iMac Pro's SMC put the Mac to sleep, or switch it off, within seconds. The sudden jump from idle to full load at the Vega's top clock speeds is what sets it off.

To stop it, T2 Zone Power holds the iMac Pro's Radeon Pro Vega at its first five clock steps (sclk states 0 to 4). On a Vega 64 that's at most 1201 MHz instead of 1350 MHz, about 11% off the top clock. The daemon checks the limit four times a second and puts it back if it's lost, for example after a GPU reset when waking from sleep. When the daemon stops, the GPU goes back to automatic clocks.

Other Macs aren't affected: the iMac Pro is the only T2 Mac with a Vega GPU.

To check that the limit is on, look for this line in the log after boot:

$ journalctl -b -u t2-zonepowerd | grep Vega
Vega 10 graphics clock held at sclk states 0-4

Gaming on a T2 iMac

  • Play at 2560×1440 and let it scale up to the full screen. Rendering a game at 5120×2880 works the GPU much harder, and hasn't been tested with the fan boost and clock limit together.
  • Some games, such as Counter-Strike 2, set the resolution back to 5K when you apply a graphics preset. Check it after changing presets.
  • Cap the frame rate if the game allows it. Without a cap, the GPU runs flat out even in menus.

The story of how we tracked this down is on the blog: Tuning the T2 iMacs for gaming.

Hardware video decoding#

Playing video on the GPU saves battery and keeps the fans quiet. VorT2x enables the RPM Fusion repositories and installs the full VA-API driver for each GPU in your Mac:

  • Intel: intel-media-driver
  • AMD: mesa-va-drivers-freeworld, which replaces Fedora's mesa-va-drivers

To check it, install libva-utils and run vainfo. It lists the video formats your GPU can decode.

$ sudo dnf install libva-utils
$ vainfo

Streaming using Sidecar#

Like Sidecar on macOS, you can use a tablet (or a phone, or another computer) as a second screen. The T2 has its own video encoder for this, so the stream doesn't load the CPU. Sunshine runs on the Mac and Moonlight shows the screen on the other device and sends touch, mouse and keyboard back.

1. Build Sunshine with V4L2 encoding

Sunshine needs V4L2 encoder support to use the T2's encoder. It's proposed upstream in Sunshine pull request #5717; until that's merged, build Sunshine with it. Install the build tools and libraries Sunshine's own build guide lists, then:

$ git clone --recurse-submodules https://github.com/LizardByte/Sunshine.git && cd Sunshine
$ git fetch origin pull/5717/head:v4l2 && git checkout v4l2 && git submodule update --init --recursive
$ cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_DOCS=OFF -DBUILD_TESTS=OFF -DSUNSHINE_ENABLE_CUDA=OFF -DSUNSHINE_ASSETS_DIR=share/sunshine
$ ninja -C build && sudo cmake --install build

This installs it as /usr/local/bin/sunshine, which is where VorT2x looks for it.

2. Configure Sunshine

Create ~/.config/sunshine/sunshine.conf:

encoder = v4l2m2m
capture = portal
hevc_mode = 1
av1_mode = 1
system_tray = disabled
  • encoder = v4l2m2m uses the V4L2 (T2) encoder.
  • hevc_mode = 1 and av1_mode = 1 keep the stream on H.264, which is what the Sidecar encoder handles.
  • capture = portal records the screen through GNOME's screen sharing.
  • system_tray = disabled stops Sunshine quitting on GNOME, which has no tray.

Run sunshine once from a terminal, open https://localhost:47990, create a user name and password, and pair Moonlight on your tablet with the PIN it shows. Then quit it.

3. Turn on the extra display

$ t2-sidecar on              # the mode used last (first time 1920x1200 at 60 Hz)
$ t2-sidecar on 2560x1600@60
$ t2-sidecar status
$ t2-sidecar off

GNOME shows a new monitor that you can arrange in Settings › Displays. t2-sidecar on also starts Sunshine; when GNOME asks which screen to share, pick the new monitor. Use the same resolution in Moonlight for the sharpest picture. t2-sidecar off, locking the screen or logging out removes the monitor and stops Sunshine.

macOS volumes#

Your macOS volumes are mounted read-only under /media/macOS at every boot, so you can open your Mac files from Fedora without any risk of changing them.

Rescue and diagnostics#

Keep your VorT2x USB stick: its live system has Wi-Fi and a few rescue tools. Run these in a terminal there:

CommandWhat it does
sudo /run/vort2x/vort2x-live-wifiBrings up Wi-Fi if no network shows up.
sudo /run/vort2x/vort2x-live-bluetoothBrings up Bluetooth on Macs whose Bluetooth runs over PCIe.
sudo /run/vort2x/vort2x-live-diagnostics --rerunWrites one diagnostics archive to a second USB drive, for bug reports.
sudo vort2x-rescueMounts your installed Fedora and opens a shell inside it (chroot).

Getting help#

The quickest way to tell us how VorT2x runs on your Mac: open Check my Mac in the VorT2x Dashboard and press Send report. It opens a report on GitHub with your Mac model, versions and the check results filled in, and nothing is sent until you submit it. Copy report gives you the same text to paste or email.

If something doesn't work, open an issue on GitHub. It helps a lot to include:

  • your Mac model (for example MacBookPro16,1: run cat /sys/class/dmi/id/product_name),
  • the VorT2x version and Fedora version,
  • ~/.local/state/vort2x/install.log, or the diagnostics archive from the USB stick.

Bluetooth says "unable to determine board type"? The PCIe Bluetooth driver only knows some models so far (MacBookAir9,1, MacBookPro15,4 and MacBookPro16,3). Please report your model rather than installing firmware by hand.

You can also write to contact@vort2x.org.
