Everything a T2 Mac needs

The hardware you love,
finally at home on Linux.

The T2 chip sits between the Mac and its keyboard, trackpad, speakers, Touch ID and more. VorT2x brings the drivers, services and fixes that make them work on Fedora.

Touch ID for login and sudo

Unlock your session and approve sudo with your fingerprint. VorT2x connects the T2's sensor to Fedora's standard fingerprint service, so nothing in Fedora has to be patched.

fprintdGDM loginsudo

A Touch Bar that earns its place

Media keys, F-keys and the keys the MacBook keyboard lacks, with haptic feedback and a Touch ID prompt. It stays dark until you touch it, which saves power.

media rowF-keyshapticsswipe layers

Speakers that sound like a Mac

Model-specific tuning for the built-in speakers and microphones, modelled on the processing macOS applies.

Wi-Fi from the first boot

The USB stick brings up Wi-Fi in the live system and carries Apple's Wi-Fi firmware into the installed one, plus Bluetooth where needed.

Fans and sensors

Fan curves, SMC temperatures and a battery charge limit, each in its own app.

Graphics, sorted

GPU control for hybrid-graphics MacBook Pros, Intel and AMD hardware video decoding, and the T2's own video encoder.

Sidecar-style second screen

Add an extended display to GNOME and stream it to a tablet, encoded by the T2 itself.

Updates without surprises

Fedora's own kernels, with the T2 modules rebuilt by DKMS. VorT2x itself only updates to releases made for your Fedora version.

How it works

Three steps. One coffee.

No kernel building, no hunting for firmware, no copying commands from forum posts.

Make the USB stick

On macOS, run one command. Pick Fedora Workstation, KDE or COSMIC and your USB drive. It downloads and checks Fedora, then adds the T2 drivers.

Install Fedora

Boot your Mac from the stick and install Fedora the normal way, with the T2 keyboard, trackpad and Wi-Fi drivers already loaded.

Let VorT2x finish

After the first login, the VorT2x installer opens by itself, updates Fedora, asks for one reboot and installs the rest.

Questions

Good to know.

Is VorT2x ready to use?

VorT2x is brand new: our first releases came out in November 2026. It carries forward code that has been used on T2 Macs before, but it hasn't been tested on hardware under the VorT2x name yet, so expect a few rough edges. Reports from real Macs help a lot.

Do I need to keep macOS?

We recommend it. You need macOS to make the USB stick, and Touch ID on Linux uses the fingerprints you enrolled in macOS. Fedora installs alongside it, and the boot-macos command restarts straight into macOS.

Which Fedora edition should I pick?

The USB maker offers Fedora Workstation (GNOME), Fedora KDE and the COSMIC spin. Workstation gets the most attention. Atomic desktops, Server and network-install images aren't supported.

Do I still get kernel updates from Fedora?

Yes. VorT2x uses Fedora's own kernels. The T2 drivers are DKMS modules, which rebuild themselves when a new kernel arrives.

What happens when Fedora 46 comes out?

Each Fedora version gets its own VorT2x release. Your Mac only updates to releases made for the Fedora version it runs, so an older Fedora keeps working until you upgrade.

Is VorT2x free?

Yes, and it's open source: the kernel modules are GPL-2.0 and everything else is GPL-3.0-or-later. If you'd like to help keep it going, you can support us on Patreon.
